Your provider can read more than you think

Encrypting the contents is the easy half. Most services still hold the file names, the folder structure, the sizes and the list of everyone you have ever shared with, which is plenty to work with. Peergos does not hold any of it.

A drive, not a website you visit

Sync any folder, in both directions, on as many devices as you like: documents, a music library, the project you are working on. Change one part of a large file and only that part goes up.

On Windows, Linux and Android it mounts as an ordinary drive in your file manager, decrypting as you open things. Calendars and contacts sync to your phone's own apps, and to Thunderbird over CalDAV and CardDAV.

Get the apps

And everything you keep in it

The apps run in a sandbox, on top of the same encrypted storage, and see only the file you opened. Write your own and it gets the same deal.

The drive itself, on any device you log in from

Share with someone, or with a secret link

Send an encrypted follow request to another Peergos user and share with them directly. Nobody, us included, can see who is connected to whom.

For everyone else there are secret links. They work for people who have never heard of Peergos, and the file is still not exposed to the server on the way. Give a link an expiry, a password, a fixed number of uses, or write access.

Sharing uses a hybrid of X25519 and MLKEM-1024, so what you share today is no good to someone who records it now and waits for a quantum computer to catch up.

Open, audited, and not ours to sell

There is no security in obscurity, so all of it is open, the server as well as the client. We have been audited twice, by Radically Open Security and Cure53, and both reports are published in full.
