Questions about paying

Why is there no free tier?

Because the money has to come from somewhere, and if it does not come from you it comes from what can be learned about you. We would rather charge for storage. If you do not want to pay us, run the server yourself: it is the same software and it costs nothing.

Can I get my data out?

Any time, without asking us. Download a folder, or your whole drive, as a zip. Sync a folder to your own disk, mount the drive and copy it, or pull it over WebDAV. Nothing is in a format only we can read.

What if Peergos disappears?

The server is open source and you can run it yourself, so the software outlives the company. You can also migrate your whole account, friends and links included, to any other server.
